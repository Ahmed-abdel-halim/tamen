# تصميم ميزة نقل المصروفات التشغيلية

## نظرة عامة على التصميم

ميزة تسمح بنقل المصروفات التشغيلية من المحاسب المالي إلى الخزينة والمصارف بشكل منظم وآمن.

## البنية المعمارية

### المكونات الرئيسية

#### 1. مكون `OperatingExpensesTransfer.tsx`
- مكون React رئيسي يدير واجهة نقل المصروفات
- يحتوي على تبويبين: المصروفات المعلقة والمصروفات المنقولة
- يتعامل مع جلب البيانات من الخادم وإرسال طلبات النقل

#### 2. تحديث `App.tsx`
- إضافة استيراد المكون الجديد
- إضافة مسار جديد: `/reports/operating-expenses-transfer`
- إضافة عنصر في القائمة الجانبية تحت "إدارة المصروفات"

### نموذج البيانات

#### المصروفة (Expense)
```typescript
{
  id: number;
  description: string;
  amount: number;
  category: string;
  date: string;
  status: 'pending' | 'transferred';
  notes?: string;
}
```

#### سجل النقل (Transfer)
```typescript
{
  id: number;
  expense_id: number;
  transfer_date: string;
  destination: 'treasury' | 'bank';
  destination_details: string;
  amount: number;
  reference_number?: string;
  status: 'completed' | 'pending';
}
```

### واجهات برمجية الخادم (APIs)

#### 1. جلب المصروفات المعلقة
```
GET /api/operating-expenses
```
- يرجع قائمة المصروفات بحالة `pending`

#### 2. جلب سجل النقل
```
GET /api/operating-expenses/transfers
```
- يرجع قائمة جميع عمليات النقل

#### 3. نقل المصروفات
```
POST /api/operating-expenses/transfer
```
- يستقبل قائمة معرفات المصروفات والوجهة والتفاصيل
- يرجع تأكيد النقل

## واجهة المستخدم

### التبويب الأول: المصروفات المعلقة

#### الجدول
- عمود اختيار (checkbox) لكل مصروفة
- الوصف
- الفئة
- المبلغ
- التاريخ
- الملاحظات

#### خيارات النقل
- **اختيار الوجهة**: قائمة منسدلة (خزينة/مصرف)
- **تفاصيل الوجهة**: حقل نص (اسم الخزينة أو المصرف والحساب)
- **رقم المرجع**: حقل نص اختياري (رقم الحوالة أو الشيك)
- **المبلغ الإجمالي**: عرض تلقائي للمبلغ المختار
- **زر النقل**: لتنفيذ عملية النقل

### التبويب الثاني: المصروفات المنقولة

#### جدول السجل
- الوصف
- الفئة
- المبلغ
- الوجهة (مع أيقونة)
- تفاصيل الوجهة
- رقم المرجع
- تاريخ النقل
- حالة النقل

## الألوان والأيقونات

- **الخزينة**: أيقونة `fa-vault` باللون الأزرق (#3b82f6)
- **المصرف**: أيقونة `fa-building-columns` باللون البنفسجي (#8b5cf6)
- **المبالغ**: باللون الأخضر (#10b981)
- **الحالة المكتملة**: خلفية خضراء فاتحة
- **الحالة المعلقة**: خلفية صفراء فاتحة

## الصلاحيات

- الميزة محمية بصلاحية `/reports/expenses` (المحاسب المالي)
- يتم التحقق من الصلاحيات في `AuthorizedRoute`

## تدفق البيانات

1. عند تحميل المكون، يتم جلب المصروفات المعلقة من API
2. المستخدم يختار مصروفات متعددة
3. يختار الوجهة ويدخل التفاصيل
4. عند النقر على "نقل"، يتم إرسال طلب POST إلى الخادم
5. يتم تحديث الجدول بالمصروفات المنقولة
6. يتم عرض رسالة تأكيد النجاح

## الحالات الخاصة

- إذا لم تكن هناك مصروفات معلقة، يتم عرض رسالة "لا توجد مصروفات معلقة"
- التحقق من صحة البيانات قبل الإرسال
- معالجة الأخطاء من الخادم وعرض رسائل خطأ واضحة
