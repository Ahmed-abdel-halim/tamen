# مهام تطبيق ميزة نقل المصروفات التشغيلية

## نظرة عامة على المهام

هذا المستند يحتوي على قائمة المهام المطلوبة لتطبيق ميزة نقل المصروفات التشغيلية.

## المهام

### المهمة 1: إنشاء مكون OperatingExpensesTransfer.tsx
**الوصف:** إنشاء مكون React جديد يدير واجهة نقل المصروفات التشغيلية.

**التفاصيل:**
- إنشاء ملف جديد: `src/components/OperatingExpensesTransfer.tsx`
- المكون يحتوي على تبويبين: المصروفات المعلقة والمصروفات المنقولة
- استخدام React Hooks (useState, useEffect) لإدارة الحالة
- جلب البيانات من واجهات برمجية الخادم
- عرض جداول بالمصروفات

**المتطلبات:**
- استخدام مكتبة React
- استخدام مكتبة React Router
- استخدام مكتبة Axios أو Fetch API للاتصال بالخادم
- استخدام مكتبة FontAwesome للأيقونات

**معايير القبول:**
1. المكون يتم تحميله بدون أخطاء
2. يتم عرض التبويبين بشكل صحيح
3. يتم جلب البيانات من الخادم بنجاح
4. يتم عرض الجداول بشكل صحيح

---

### المهمة 2: تطبيق تبويب المصروفات المعلقة
**الوصف:** تطبيق تبويب المصروفات المعلقة مع جدول وخيارات النقل.

**التفاصيل:**
- عرض جدول بالمصروفات المعلقة
- إضافة خانات اختيار لكل مصروفة
- عرض الأعمدة: الوصف، الفئة، المبلغ، التاريخ، الملاحظات
- إضافة قائمة منسدلة لاختيار الوجهة (خزينة/مصرف)
- إضافة حقل نص لتفاصيل الوجهة
- إضافة حقل نص اختياري لرقم المرجع
- عرض المبلغ الإجمالي المختار
- إضافة زر "نقل المصروفات"

**المتطلبات:**
- استخدام مكتبة React
- استخدام مكتبة FontAwesome للأيقونات
- استخدام CSS للتنسيق

**معايير القبول:**
1. يتم عرض الجدول بشكل صحيح
2. يمكن اختيار مصروفات متعددة
3. يتم حساب المبلغ الإجمالي تلقائياً
4. يتم عرض خيارات النقل بشكل صحيح
5. الزر معطل إذا لم يتم اختيار مصروفات أو وجهة

---

### المهمة 3: تطبيق تبويب المصروفات المنقولة
**الوصف:** تطبيق تبويب المصروفات المنقولة مع جدول السجل.

**التفاصيل:**
- عرض جدول بسجل المصروفات المنقولة
- عرض الأعمدة: الوصف، الفئة، المبلغ، الوجهة، تفاصيل الوجهة، رقم المرجع، تاريخ النقل، الحالة
- عرض أيقونة مناسبة لكل وجهة (خزينة/مصرف)
- عرض الحالة بألوان مختلفة (مكتملة/معلقة)

**المتطلبات:**
- استخدام مكتبة React
- استخدام مكتبة FontAwesome للأيقونات
- استخدام CSS للتنسيق

**معايير القبول:**
1. يتم عرض الجدول بشكل صحيح
2. يتم عرض الأيقونات بشكل صحيح
3. يتم عرض الحالة بألوان مختلفة
4. يتم عرض رسالة إذا لم تكن هناك مصروفات منقولة

---

### المهمة 4: تطبيق وظيفة نقل المصروفات
**الوصف:** تطبيق وظيفة نقل المصروفات إلى الخادم.

**التفاصيل:**
- عند النقر على زر "نقل المصروفات"، يتم إرسال طلب POST إلى الخادم
- البيانات المرسلة: قائمة معرفات المصروفات، الوجهة، تفاصيل الوجهة، رقم المرجع
- معالجة الاستجابة من الخادم
- عرض رسالة تأكيد النجاح
- تحديث الجداول بعد النقل الناجح
- معالجة الأخطاء وعرض رسائل خطأ واضحة

**المتطلبات:**
- استخدام Axios أو Fetch API
- استخدام مكتبة Toast أو Alert لعرض الرسائل

**معايير القبول:**
1. يتم إرسال الطلب بشكل صحيح
2. يتم عرض رسالة تأكيد النجاح
3. يتم تحديث الجداول بعد النقل
4. يتم معالجة الأخطاء بشكل صحيح

---

### المهمة 5: تحديث App.tsx
**الوصف:** تحديث ملف App.tsx لإضافة المسار والقائمة الجانبية.

**التفاصيل:**
- استيراد المكون الجديد `OperatingExpensesTransfer`
- إضافة مسار جديد: `/reports/operating-expenses-transfer`
- إضافة عنصر في القائمة الجانبية تحت "إدارة المصروفات"
- التأكد من أن الصلاحيات صحيحة

**المتطلبات:**
- تعديل ملف App.tsx
- استخدام مكون `AuthorizedRoute` للتحقق من الصلاحيات

**معايير القبول:**
1. يتم استيراد المكون بشكل صحيح
2. يتم إضافة المسار بشكل صحيح
3. يتم إضافة عنصر القائمة بشكل صحيح
4. يتم التحقق من الصلاحيات بشكل صحيح

---

### المهمة 6: اختبار الميزة
**الوصف:** اختبار الميزة للتأكد من أنها تعمل بشكل صحيح.

**التفاصيل:**
- اختبار عرض المصروفات المعلقة
- اختبار اختيار مصروفات متعددة
- اختبار حساب المبلغ الإجمالي
- اختبار نقل المصروفات
- اختبار عرض سجل المصروفات المنقولة
- اختبار معالجة الأخطاء
- اختبار الصلاحيات

**المتطلبات:**
- اختبار يدوي في المتصفح
- اختبار مع بيانات حقيقية من الخادم

**معايير القبول:**
1. جميع الميزات تعمل بشكل صحيح
2. لا توجد أخطاء في وحدة التحكم
3. الواجهة تبدو جيدة
4. الصلاحيات تعمل بشكل صحيح
